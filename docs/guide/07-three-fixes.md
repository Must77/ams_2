# 07 三个修复：数学、代码与开关

> 前置：05、06。目标：对每个修复说清"数学上为什么对、代码改在哪、开关叫什么、
> 不开会怎样"。所有修复都是 **opt-in 选项，默认关闭**，eg_1 旧路径行为零变化
> （黄金哈希 `342042...d266` 全程一致）。

## 修复 1：边长反缩放（`-fortran_upper_unscale_edge_len`）

**问题**：对方矩阵 `A' = S·A·S`（S = diag(边长)，02 篇约定 B），与代码 ±1 的 G 失配。

**数学**：不去改 G，而是把整个系统变回约定 A 再解。设原问题 `A'·x' = b'`，则：

```text
A'·x' = b'
S·A·S·x' = b'
A·(S·x') = S⁻¹·b'         ← 两边左乘 S⁻¹
令 x = S·x', b = S⁻¹·b':   A·x = b      ← 这是 Whitney 约定下的系统，AMS 配套齐全
解出 x 后还原:  x' = S⁻¹·x   （每个分量除以对应边长）
```

**代码**（`PetscAMGInterface.cc`）：
- `prepare_fortran_upper_1based_inputs()`：展开成全量 CSR 后，矩阵值
  `val[k] /= len_r · len_c`（行右乘列乘各一个 S⁻¹），右端项 `rhs[r] /= len_r`；
  边长由节点坐标现算，零长度边触发 PetscCheck 报错；
- `solve_eg1_fortran_upper_1based()`：返回前 `out[e] /= len_e`（配对反变换）。
  两处必须同开同关——开关读的是同一个 PETSc 选项，天然同步。

**不开的后果**：AMS 的 β 空间修正方向全错，外层残差降到 1e-4~1e-5 后死停，
解收敛到错误答案（历史上的 0.485 差异）。

**为什么不直接缩放 G**（曾尝试，已废弃）：Hypre 内部用 G 的 ±1 数值构造 Π 插值阵，
非 ±1 的 G 让辅助空间退化，第一次应用就 NaN。教训记在提交信息和 06 篇。

## 修复 2：手工 β Poisson 矩阵（`-ams_beta_mass_poisson`）

**问题**：Hypre 默认自建 β 矩阵 `Aβ = Gᵀ·B·G`，其中 B = Kr + M。理论上
`Gᵀ·Kr·G ≡ 0`（02 篇恒等式的两侧版本），实际数据只有 8 位有效数字：

```text
GᵀKrG 的对角元 = 一串 O(1) 量级数字的代数和，理论和为 0
   每个数字带 ~1e-8 相对截断误差
→ 残留噪声 ~1e-8 × 量级，符号随机
空气区真实信号 (GᵀMG 的贡献) ~ 1e-4 × 1e-8 量级 ← 比噪声还小
→ 实测 17,120 个负对角（最小 −1.13e-7，正是噪声水平）
```

拉普拉斯矩阵带负对角，BoomerAMG 的插值构造（含开方、比值）直接产出 NaN。

**数学**：β 空间真正该解的算子本来就是 σ 加权拉普拉斯 `Gᵀ·M·G`（Kr 部分理论为零，
本不该出现）。直接构造它：M 的元素是小正数量级的质量 Gram 元素，**没有大数相消**，
8 位精度完全够用。

**代码**（`create_pc()`）：`MatPtAP(M副本, G)` 计算 `GᵀMG`，喂给
`PCHYPRESetBetaPoissonMatrix()`。PETSc 3.24 原生暴露这个接口。

**不开的后果**（在修复 1 开启的前提下）：内层第 0 步 `DIVERGED_NANORINF`，
返回零向量，外层 happy-breakdown 假收敛，输出全零解。

## 修复 3：质量矩阵对角位移（`-ams_beta_mass_shift`，默认 1e-6）

**问题**：修复 2 后 β 矩阵干净了，但它是跳系数 ~1e12 的拉普拉斯（空气 σ 与地下 σ 之比），
BoomerAMG 对如此极端的系数跳跃力不从心：内层迭代停滞在相对残差 ~6e-2。

**数学**：给**只用于构造预条件器**的 M 副本加一个小的正对角位移：

```text
M_pc = M + ε·‖M‖∞·I    （ε 默认 1e-6）
→ Aβ_pc = Gᵀ·M_pc·G = GᵀMG + ε‖M‖∞·GᵀG
```

`GᵀG` 是图拉普拉斯（均匀系数），相当于给空气区一个人工最小电导率，AMG 看到的
系数对比被封顶在 ~1/ε。**关键性质**：位移只进预条件器；外层 Krylov 迭代用的算子
仍是精确的 A，预条件器不精确只影响收敛快慢、不影响收敛到的答案（这是预条件
Krylov 方法的基本性质）。实测 ε 从 1e-8 到 1e-2 跨 6 个量级效果相同（内层都是
~3 步收敛），说明这个旋钮极其鲁棒、不需要调。

**代码**（`create_pc()` 同一段）：`MatDuplicate` 复制 M（**绝不能动 ctx->M 本体**，
它还是外层算子的一半）→ `MatShift` → `MatPtAP` → 喂 Hypre。

**不开的后果**：内层每次磨到迭代上限还不达标，外层每步消耗 50~100 倍的内层迭代，
收敛慢到不可用（实测外层 40 步才降到 0.44）。

## 配套约定：内层用 GMRES（命令行 `-B_ksp_type gmres`，未硬编码）

FCG 在近奇异模态上会因浮点曲率误报 `DIVERGED_INDEFINITE_MAT` 提前退出（05 篇 6 节）。
代码默认仍是 FCG（保持旧行为），标准运行命令里显式带 `-B_ksp_type gmres`。
若日后确认无副作用，可考虑把默认值改成 GMRES（一行改动 + 跑回归）。

## 三个修复的依赖关系

```text
修复1 (反缩放)  ──必须先开──>  修复2 (干净β)  ──必须先开──>  修复3 (位移)
   │                             │                            │
   不开: 收敛到错解               不开: NaN 全零解              不开: 慢 50~100 倍
```

顺序不可乱：修复 2/3 是修复 1 揭出来的问题（旧约定下 Kr 污染反而把 β 对角抬正了，
NaN 和停滞都被掩盖着）。这种"修一层露一层"的洋葱结构是 06 篇侦探故事的主线。

## 标准运行命令（汇总）

```bash
./build_ubuntu/UpperExampleCheck ~/ams_example \
  -fortran_upper_unscale_edge_len \
  -ams_beta_mass_poisson \
  -ams_beta_mass_shift 1e-6 \
  -B_ksp_type gmres -B_ksp_max_it 15 \
  -em_outer_max_it 60 -em_outer_rtol 1e-7
```

各选项含义与调法见 10 篇选项表。
