# 00 总览与阅读地图

> 本目录是为接手者（CS 背景、有 Fortran 有限元项目经验、不熟悉电磁物理与迭代求解器）
> 写的从零到全貌的解释文档。2026-06-13 写于 AMS 路径打通之后。

## 这个项目在干什么（一段话版本）

合作方（地球物理团队）有一个 Fortran 程序，用有限元法模拟大地电磁场，核心步骤是解一个
约 68 万未知数的复数稀疏线性方程组 `A·x = b`。他们现在用**直接求解器**（类似 LU 分解），
结果可信但内存吃不消，希望换成**迭代求解器**。这类电磁问题的迭代法必须配一种叫 **AMS**
的专用预条件器才收敛得动。本仓库就是那个"迭代求解器 + AMS"的 C++ 原型：先用 PETSc/Hypre
把对方给的算例解对，再做成可供 Fortran 直接调用的函数接口。

## 故事到哪一步了（一段话版本）

对方给的大算例（`ams_example`，682,344 条边）此前一直解不对：迭代卡死、解和对方参考解差
48.5%。2026-06-13 我们定位并修复了三层相互掩盖的问题（边长缩放约定、8 位数据精度噪声、
极端电导率对比），现在 AMS 解代回方程的残差是 **7.1e-8，比对方直接解的 6.8e-7 还准一个量级**。
剩余的"解与参考解差 69%"被证明是**空气层规范自由度**造成的假差异（物理上不可观测的分量），
不是错误——这正是需要和对方交涉验收标准的原因。

## 角色表

| 名字 | 是什么 |
| --- | --- |
| 对方 / 合作方 | 地球物理团队，Fortran 程序的作者，数据和参考解的来源 |
| `ams_example` | 对方导出的大算例：矩阵（上三角 CSR）、网格（节点/边）、右端项、参考解 |
| `slove.txt` | 对方直接求解器算出的参考解（注意：它不是"真理"，见 08 篇） |
| `eg_1` | 仓库自带的小算例（3,124 条边），AMS 路径在它上面一直是好的，全程当回归基准 |
| PETSc | 美国阿贡实验室的稀疏线性代数框架，提供矩阵/向量/Krylov 求解器/预条件器接口 |
| Hypre / AMS | LLNL 的多重网格库；AMS 是其中专为电磁 curl-curl 方程设计的预条件器 |
| `FemAms` | 旧文件式入口：读 eg_1 格式的文件并求解 |
| `UpperExampleCheck` | 大算例检查程序：读对方格式数据 → 调 adapter 求解 → 与 slove.txt 比对 |
| `AdapterSelfCheck` | 小型单元测试：验证 1 基转 0 基、上三角展开等纯逻辑 |
| `UpperDumpSystem` / `AmsLab` | 本轮新增的诊断工具：把系统存成二进制 + 秒级试参实验台 |
