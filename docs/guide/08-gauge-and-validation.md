# 08 规范自由度与验收标准：为什么差 69% 不是错

> 前置：01、06。这是与对方交涉的理论核心。读完你应该能向任何人解释清楚：
> "两个解都对，但它们可以差 69%"这句话为什么成立。

## 1. 现象回顾

全部修复后的终局数字：

```text
slove.txt（对方直接解）代回 A·x=b:   相对残差 6.81e-07
AMS 解（本仓库）代回 A·x=b:          相对残差 7.14e-08   ← 好一个量级
两个解的全局相对 L2 差:               0.690               ← ?!
```

按朴素直觉"残差小=解准"，0.69 的差异不可理喻。解释需要一个概念：**方程没有把解
完全定死**。

## 2. 用 CS 的语言：病态方向上的欠定

考虑一个简化模型。设 A 对称，有特征分解；某个特征方向 v 的特征值 λ = 1e-12
（本问题空气区梯度模态的真实量级，01 篇）。两个候选解 x₁、x₂ = x₁ + c·v：

```text
残差变化:  ‖A·x₂ - b‖ = ‖A·x₁ - b + c·λ·v‖ ≤ ‖A·x₁ - b‖ + |c|·1e-12
```

c 取 1e5，残差只变 1e-7——**在残差 1e-7 的精度下，v 方向上加减 1e5 都是"同样好"的解**。
方程在这个方向上近乎欠定，解出什么取决于算法的偶然选择：

- 直接求解器（LU 类）：消元过程隐式地为这些方向选了一个确定值（取决于消元顺序、
  舍入的累积——本质上是任意的）；
- Krylov 迭代法：初值为零、残差对这些方向"近视"，基本不往里放分量——又是另一个
  任意值。

两个算法都没错，它们只是在**方程管不着的子空间**里各自落在了不同的点。
物理里这叫**规范自由度**（gauge freedom）；数值线性代数里这叫近零空间欠定。
（如果你愿意类比：好比解欠定最小二乘，最小范数解和某个特解都满足方程，
但二者之差在零空间里可以任意大。）

## 3. 法证证据：差向量解剖

对差向量 d = x_AMS − x_slove 做了两个独立分解（探针脚本逻辑见 06 篇 9 节）：

**按物理区域分**（低 σ "空气"边 = |Ki_ii|/|Kr_ii| < 1e-7，占 39.3%）：

```text
d 的能量落在空气边上的比例:     100.0000%
在地下（高 σ）边上两解的相对差:  3.2e-05    ← 与 8 位数据精度同量级
```

**按模态类型分**（最小二乘投影到梯度空间 range(G)）：

```text
d 的实部中梯度场占比:  96.3%
d 的虚部中梯度场占比:  96.1%
```

两个分解互相印证，且与 01 篇的理论预言严丝合缝：**差异 = 空气区的梯度模态 =
方程近视的那个子空间**，不多不少。如果 0.69 是真误差（算法错了），它没有理由
如此精确地只待在这一个子空间里。

## 4. 为什么以前没人发现（直接解时代这不是问题）

对方一直用直接求解器，输出天然是"那一个确定的代表元"，下游怎么比对都自洽。
引入迭代法后规范自由度首次暴露。换句话说：**这不是我们引入的问题，是迭代法
让一个一直存在的数学事实显形了**。任何迭代法（不止 AMS）都会有此现象。

## 5. 对验收标准的三个结论

1. **"与 slove.txt 全局 L2 比对"不可用作迭代解的验收标准**——它要求迭代法复现
   直接法在欠定子空间里的任意选择，数学上不可能稳定达成。
2. **可用的验收标准**（按推荐顺序）：
   - 代回残差 `‖A·x−b‖/‖b‖`（最干净，已达 7.1e-8）；
   - 高 σ 区域（或感兴趣体积）的 L2 比对（已达 3.2e-5）；
   - 接收点位置的场值/视电阻率比对（最贴近物理使用场景，需要对方的接收点列表）。
3. **如果对方确实需要空气区数值也一致**（例如下游程序读全场）：在迭代解之后加一步
   **规范固定**后处理——把解投影到与直接解相同的规范选择上（例如对空气区梯度分量
   做一次 σ 加权投影消除）。这是后处理问题，不影响求解器本身，工作量可控。

## 6. 一个待对方确认的旁证

合作方自己的旧 AMS 程序（"个人电脑十分钟跑完"那个）如果当年验收通过过，
它几乎必然也只在导电区/接收点比对过——同样的规范自由度对它一样存在。
这是 09 篇交涉问题清单里的第 2 问，答案能直接佐证我们的分析。
