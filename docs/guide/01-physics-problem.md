# 01 物理与数学问题：方程从哪里来

> 前置：00。目标：明白 `A = Kr + i·Ki` 这两块矩阵各自的物理身份，以及"空气层"
> 为什么会成为后面一切麻烦的源头。

## 1. 场景：频域大地电磁勘探

地球物理勘探的一类基本方法：在地面（或海里）布置一个交变电流源，电磁场穿透大地，
地下不同电导率（导电能力）的岩层对场的响应不同；在接收点测量场值，反推地下结构
（找矿、找油气、找水）。

关键物理量是**电导率 σ**（单位 S/m），它在计算域内的对比极其悬殊：

| 介质 | σ 量级 |
| --- | --- |
| 空气 | 1e-8 以下（理想为 0，数值上设个小正数） |
| 淡水/岩石 | 1e-4 ~ 1e-2 |
| 海水 | ~3 |
| 矿体 | 可达 1e2 |

计算域必须包含一大块空气（场在空气里也存在），所以矩阵里约 39% 的未知数
（本算例 267,989 / 682,344 条边）位于低 σ 区。**记住这个事实**，它是 07、08 两篇
的主角。

## 2. 从 Maxwell 方程到我们的线性系统

源以单一频率 ω 振荡时，设场随时间按 e^{±iωt} 变化（正负号是"时谐约定"，两种都有人用，
这正是 03 篇符号约定问题的来源），Maxwell 方程组化成关于复振幅电场 E 的方程：

```text
∇ × (μ⁻¹ ∇ × E)  ±  iωσ E  =  -iω J_s
└──── 刚度项 ────┘   └质量项┘     └源项┘
```

- μ 是磁导率（基本是常数），∇× 是旋度算子；
- 左边第一项离散后是实对称矩阵 **Kr**（curl-curl 刚度阵），和你熟悉的拉普拉斯刚度阵
  地位相同，但算子换成了"旋度的旋度"；
- 第二项离散后是 **±ωσ 加权的质量阵 Ki**（虚部）。和你项目里的质量阵一样按单元积分
  组装，只是权重是 σ；
- 频率低（地球物理常用 0.1~1000 Hz）时位移电流 ω²εE 可忽略，所以实部里只有 curl-curl，
  **没有**正定的质量项压底——这是数值困难的根源之一。

离散后得到复线性系统：

```text
(Kr + i·Ki) x = b,   Kr, Ki 实对称,  x, b 复向量
```

本算例规模：682,344 复未知数，全量 CSR 非零元 11,181,876。

## 3. 两个矩阵的"性格"

**Kr（curl-curl 刚度阵）**：对称半正定，但有一个巨大的零空间——所有"梯度场"。
因为旋度的基本性质 ∇×(∇p) ≡ 0：任何标量势 p 的梯度场代进刚度项都得零。离散后
零空间维数 ≈ 节点数（本算例 97,901）。也就是说 **Kr 有约 9.8 万个零特征值方向**。
（你做结构/热的有限元时拉普拉斯刚度阵只有常数这 1 维零空间，被边界条件轻松杀掉；
这里是 9.8 万维，杀不掉，只能靠虚部项"压住"。）

**Ki（σ 质量阵）**：对称，符号取决于时谐约定（本算例数据全负，eg_1 全正，见 03）。
它在梯度方向上提供唯一的"刚度"：梯度场 ∇p 代入完整方程剩下 ±iωσ∇p。于是：

```text
系统在梯度方向上的"可观测度" ∝ 当地的 σ
```

地下 σ~1e-2：梯度分量被约束得不错。空气 σ~1e-8 甚至更小：**梯度分量几乎不受方程约束**
——方程对它们"近视"。这一事实有两个后果：

1. 迭代法收敛极慢（条件数被这些近零模态撑爆）→ 这正是 AMS 预条件器存在的意义（05 篇）；
2. 即使解出来了，空气区梯度分量也是"方程随便给的"——不同算法给出不同值，都满足方程
   → 这就是最后 69% 假差异的来历（08 篇）。

## 4. 与你的二维大地电磁正演项目的对照表

好消息：物理背景你已经有了——频域、电导率、空气层这些概念和你的二维 MT 完全同源。
本项目本质上是"同一物理的三维有源版本"，主要的新东西全部来自维度升级：

| 你的二维 MT 正演 | 本项目（三维有源 EM） | 升维带来的变化 |
| --- | --- | --- |
| 无源（平面波激励，边界条件进场） | 有源（可控源，右端项 b 来自电流源） | rhs 大部分是 0，源附近非零 |
| TE/TM 解耦，未知数是**标量**（Ex 或 Hx） | 不解耦，未知数是**矢量** E 的三个分量 | 这是一切的分水岭 |
| 标量场 → 节点元天经地义 | 矢量场 → 必须换**棱边元**（02 篇） | 你从没碰过棱边元是正常的，二维 MT 用不到 |
| 标量 Helmholtz 刚度阵，零空间平凡 | curl-curl 刚度阵 Kr，零空间 ~10 万维 | 迭代法的噩梦来源 |
| 复系统（你应该处理过 iωμσ 项） | 同样复系统，但实数化成 2N×2N（03 篇） | PETSc 实数版的工程选择 |
| 规模小，直接解/简单迭代够用 | 68 万复未知数 | 必须 Krylov + AMS 预条件（04、05 篇） |
| MPI 并行 | 当前原型单进程（PETSc 天然可并行，未来工作） | 你的 MPI 经验之后会用上 |
