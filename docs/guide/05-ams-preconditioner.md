# 05 AMS 预条件器：为什么需要它，它需要什么

> 前置：02、04。目标：理解 AMS 的工作原理到"能解释它为什么会失灵"的深度。
> 不要求会推导收敛性证明。

## 1. 迭代法为什么在这个问题上裸奔必死

Krylov 迭代法（CG/GMRES 家族）的收敛速度由矩阵特征值分布决定：特征值聚成一团收敛快，
散布悬殊收敛慢。内层矩阵 B = Kr + |Ki| 的特征值结构（01、02 篇的结论翻译过来）：

```text
旋度类模态:   特征值 ~ O(刚度)            ← Kr 管着, 量级正常
梯度类模态:   特征值 ~ O(ω·σ·当地尺度)     ← 只有 Ki 管, σ 跨 10 个量级
```

≈9.8 万个梯度模态的特征值从"正常"(地下)一路散到"几乎是零"(空气)，条件数 ~1e12。
实测对照（06 篇探针）：无预条件 GMRES 跑 100 步残差只降到 0.33；普通的 Jacobi 预条件
也一样烂。**这不是调参能救的，是谱结构性的**。

## 2. AMS 的思想：把零空间"指名道姓"地交给多重网格

AMS = Auxiliary-space Maxwell Solver（Hiptmair–Xu 2007 理论，Hypre 实现）。
核心观察：既然病根是"梯度模态"和"旋度模态"混在一个空间里，那就**显式分解**：

```text
任意边自由度向量 u  ≈  (光滑残量)  +  Π·(矢量节点场)  +  G·(标量节点势)
                       ↑平滑器处理      ↑"α空间"           ↑"β空间"
```

- **G**（02 篇的离散梯度，边数×节点数）：把梯度模态拉回到**节点标量**世界。
  在那个世界里它们对应的算子是 `Aβ = Gᵀ·B·G` ——一个 **σ 加权的标准节点拉普拉斯**！
  这是你最熟悉的矩阵类型，代数多重网格（AMG，可理解为"自动几何多重网格"）解它易如反掌。
- **Π**（插值阵，边数×3·节点数）：把"逐分量光滑的矢量场"从节点世界映到边世界，
  对应算子 `Aα = Πᵀ·B·Π` 是矢量拉普拉斯，同样交给 AMG。
- Hypre 不要求用户给 Π：它用 **G 的稀疏结构和 ±1 数值** 加 **节点坐标** 自动构造
  （`PCSetCoordinates` 喂坐标就是为这个）。

一次 AMS 应用 ≈ 在"边空间平滑 → β 空间 AMG → α 空间 AMG"之间走一圈（cycle type 可选）。
对标准 curl-curl 问题，AMS 让迭代步数与网格规模基本无关——这是它成为这类问题
标配的原因，也是本项目立项的前提。

## 3. AMS 的三个输入契约（每一条都对应一层事故）

| 契约 | 破坏后的症状 | 对应本项目 |
| --- | --- | --- |
| ① G 必须正确刻画 B 的近零空间（即 Kr·G≈0 成立） | 不报错，预条件器"安静地"失效：β 空间修正的全是错误方向，外层残差降到某处死停 | 第一层事故：边长缩放使 Kr·G≠0（修复 1） |
| ② G 必须是 ±1 关联矩阵的形态 | Hypre 用 G 的数值构造 Π；非 ±1 时 Π 退化，预条件器输出垃圾/零向量 | 我们试过 G'=±1/len 的"快捷修复"，立即 NaN——被否决（06 篇） |
| ③ 内部 AMG 拿到的 Aβ、Aα 必须是体面的（类）拉普拉斯阵 | AMG 的插值构造里有除法/比值，遇到负对角或 1e12 跳系数会产生 NaN 或失效 | 第二、三层事故：消去噪声负对角 + σ 对比（修复 2、3） |

## 4. 把三层事故重述成 AMS 语言（一段话）

对方矩阵带边长缩放（破坏①）→ 反缩放修好①后，Hypre 默认用 `Gᵀ·B·G` 自建 β 矩阵，
但 8 位精度数据让本应精确归零的 `Gᵀ·Kr·G` 留下 ~1e-8 噪声，空气区的真实 σ 信号比噪声
还小，β 矩阵出现 17,120 个负对角（破坏③-NaN 分支）→ 我们绕开自建、手工给
`Aβ = Gᵀ·M·G`（M 只含质量项，没有消去、没有噪声）修好 NaN 后，β 矩阵成了干净但
跳系数 1e12 的拉普拉斯，BoomerAMG 在空气区仍然无力（破坏③-失效分支）→ 给 PC 专用的
M 副本加 1e-6 相对对角位移，把 AMG 看到的对比封顶 → 内层 3 步收敛，全线打通。

## 5. 实测效果汇总（AmsLab 实验台数据）

内层 B 系统、物理右端项、目标 rtol 1e-2：

| 配置 | 结果 |
| --- | --- |
| 无预条件 GMRES | 100 步停在 0.33，不收敛 |
| AMS（修复前，G 失配） | 能跑但方向错：外层假收敛到错解（历史 0.485 差异） |
| AMS + 反缩放（① 修复） | 第一次应用即 NaN（DIVERGED_NANORINF） |
| AMS + 反缩放 + 干净 β（①② 修复） | 不再 NaN，停滞在 6e-2 |
| AMS + 全部三修复 | **3 步收敛** |

外层（FGMRES）配上全修复内层：前 8 步从 1.0 降到 3.4e-4，最终解代回残差 7.1e-8。

## 6. FCG vs GMRES 的内层坑（独立的小教训）

代码原选内层 KSPFCG（Flexible CG）：理论上 B 对称正定时最省内存。但空气区近零模态
让浮点意义上的曲率 pᵀBp 在某些右端项下计算为非正，FCG 的防御机制立即以
DIVERGED_INDEFINITE_MAT 退出（第 2 步就停），返回半成品向量污染外层。GMRES 没有
正定性假设，不踩这个坑。所以标准命令里固定 `-B_ksp_type gmres`。
（数学上 B 确实正定——我们用 300 步×3 次随机右端项的 CG 负曲率扫描验证过，最小相对
曲率 +37.8——是浮点 + 近奇异的组合触发了 FCG 的误报。）
