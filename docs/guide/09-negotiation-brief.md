# 09 交涉简报：给合作方的问题清单与证据

> 前置：08。本篇写成可直接摘抄/转述给对方的形式（除"预案"小节是给自己人看的）。
> 背景铺垫请引用 08 篇；技术细节后援是 06、07 篇。

## 一、我们这轮的结论（先报喜）

迭代求解器（AMS 路径）已在你们提供的 682,344 边算例上打通：

| 指标 | 数值 |
| --- | --- |
| 解代回 A·x=b 的相对残差 | **7.1e-8**（你们 slove.txt 为 6.8e-7） |
| 导电区域与 slove.txt 的相对 L2 差 | **3.2e-5** |
| 单核求解耗时（含 5 分钟文本读入） | ~35 分钟，后续有数倍优化空间 |

定位并修复的关键点：你们的边元采用单位切向归一化基（矩阵相当于 Whitney 基下
左右各乘一个边长对角阵），我们的 AMS 离散梯度按 Whitney 约定构造，两者失配导致
预条件器失效。已在接口层自动适配，你们侧无须改动。

## 二、需要你们确认/提供的五件事（按优先级）

**1. 基函数约定确认**
你们的棱边元基函数是否做了单位切向归一化（自由度 = 切向场值而非环量）？
我们从数据反解出该关系并以 8 位精度验证吻合，但希望从你们程序源头确认一句，
避免我们对巧合建模。

**2. 你们旧 AMS 程序的验收方式**
你们之前能十分钟跑完的 AMS 版本，当年和直接解比对时用的是什么标准？
全场逐点比、导电区比、还是接收点场值比？（背景见第三节——我们有理由认为
全场逐点比对任何迭代法都不成立。）另请提供该版本的求解参数/库版本，便于性能对标。

**3. 验收标准协商**
基于第三节的分析，我们建议验收采用：代回残差 + 导电区（或你们指定的兴趣区域）L2 +
接收点场值三件套。若你们同意，请提供接收点列表/兴趣区域定义。

**4. 是否需要空气区数值一致**
你们的下游流程是否会读取空气区域的场值？若是，我们在迭代解后追加一步规范固定
后处理即可对齐；若否（只用地下/接收点），现状已满足。

**5. 数据精度**
能否将矩阵/右端项导出为 16 位有效数字（双精度完整精度）？当前 8 位文本是可达
精度的硬上限（也是我们必须做特殊数值处理的根源之一）。顺带建议直接导出二进制
或至少压缩文本（我们有现成的转换与校验工具）。

## 三、需要向对方解释的核心论点（可口头转述）

频域电磁方程在空气里对"梯度型"分量几乎没有约束（约束强度正比于当地电导率，
空气电导率比地下小 8~12 个数量级）。因此同一个方程存在一族"几乎同样好"的解：
它们在地下完全一致，在空气区的梯度分量上各取一值。直接求解器输出其中一个
（由消元过程随机决定），迭代法输出另一个。我们实测两者的差异 **100% 位于空气区、
96% 是纯梯度场、地下吻合到 3.2e-5**——这正是上述数学结构的指纹，不是误差。
所以"与直接解全场逐点一致"这个标准需要换成物理上有意义的比对。

## 四、预案（内部参考，不发对方）

| 对方可能的回应 | 我们的对策 |
| --- | --- |
| "基函数确实是归一化的" | 最优结局，关闭第 1 问；adapter 保持现状 |
| "不是归一化的/不清楚" | 请他们给出组装代码里基函数定义的片段；我们的反解证据（8 位精度吻合 1/len）足够硬，大概率是他们记忆有误 |
| "旧 AMS 当年就是全场比的" | 追问当年比对的容差和通过记录；若真全场通过过，要来当年的可执行/参数复跑——理论上不可能，多半是当年比的导电区 |
| "必须空气区也一致" | 排期做规范固定后处理（投影法），预估改动集中在求解后、不碰求解器 |
| "16 位数据导不了" | 接受 8 位，向他们明示精度地板：残差极限 ~1e-7、导电区比对极限 ~1e-5，写进验收协议 |
| 对性能提出要求（对标十分钟） | 现成路线：去掉 dual-mode 重复求解（省一半）、二进制 I/O（省 5 分钟）、MPI 并行（PETSc 原生支持）；对标前先拿到他们的硬件/参数（第 2 问） |
